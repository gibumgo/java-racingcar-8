# 🚗 java-racingcar-precourse

## 프로젝트 개요 및 목표
> 1. TDD 기반으로 기능을 구현하고, 테스트와 구현을 1:1로 대응
> 2. 확장성과 유지보수를 고려한 객체지향 설계 적용
     >    - 원시값 포장 객체(Name, CarNumber) 활용
>    - 자동차 컬렉션을 일급 컬렉션(Cars)으로 관리
>    - 이동 전략(MovingStrategy) 인터페이스 적용
> 3. MVC 패턴을 활용하여 입력, 도메인, 출력 책임 분리
> 4. 작은 단위 기능별로 커밋하며, 커밋 메시지와 테스트를 연계
> 5. 🔥 구현 단계에서 1주차 피드백 반영

## ✨ 기능 구현 목록

### 자동차 이름과 시도 횟수 입력
- [x] 경주할 자동차의 이름을 입력받는다.
    - [x] 이름은 쉼표(,)를 기준으로 구분한다.
    - [x] 각 자동차 이름은 1자 이상 5자 이하만 가능하다.
    - [x] 이름이 비어있거나 5자를 초과하면 예외를 발생시킨다. (`IllegalArgumentException`)
- [ ] 시도할 횟수를 입력받는다.
    - [x] 시도 횟수는 0 이상의 값이여야 한다.
    - [x] 음수이거나 숫자가 아닌 경우 예외를 발생시킨다. (`IllegalArgumentException`)

###  자동차 목록 생성 및 관리
- [x] 입력받은 자동차 이름들을 기준으로 경주에 참여할 자동차 목록을 생성한다.
- [x] 중복된 이름이 포함되어 있을 경우 예외를 발생시킨다. (`IllegalArgumentException`)
- [x] 이름이 비어 있을 경우 예외를 발생시킨다. (`IllegalArgumentException`)
- [ ] 모든 자동차의 현재 상태(이름과 위치)를 관리한다.

### 자동차의 이동 규칙
- [x] 자동차는 매 턴마다 0에서 9 사이의 무작위 값을 구한다.
- [x] 구한 값이 4 이상이면 자동차는 전진한다.
    - [x] 4 미만이면 자동차는 멈춘다.
- [x] 자동차의 위치는 전진할 때마다 1씩 증가한다.
- [x] 자동차의 위치는 0 미만 이면 예외를 발생시킨다. (`IllegalArgumentException`)

### 경주 진행
- [x] 사용자가 입력한 시도 횟수만큼 경주를 반복한다.
- [x] 각 시도마다 모든 자동차가 한 번씩 이동한다.
- [ ] 매 시도 후 각 자동차의 이동 결과를 출력한다.
- [x] 남은 시도 횟수가 0이 되면 경주를 종료한다.

### 경주 결과 출력
- [ ] 매 시도 결과를 출력할 때, 자동차 이름과 이동한 거리를 `-`로 표현한다.
    - 예: `pobi : --`, `woni : ----`
- [ ] 모든 시도가 끝난 후, 최종 우승자를 출력한다.
    - [x] 가장 멀리 이동한 자동차가 우승한다.
    - [ ] 우승자가 여러 명일 경우 쉼표(,)로 구분하여 함께 출력한다.
